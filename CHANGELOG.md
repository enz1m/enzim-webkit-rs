# Changelog

## 0.2.0 — 2026-11-19

- Allow recently viewed tabs to defer their first background memory release.
- Forward pointer hover to unfocused web views.
- Include middle-button background intent in popup events.
- Support authenticated HTTP and SOCKS5 upstream proxies.
- Update the public enzUI and iced pins and select native runtime v0.1.1.

## 0.1.0 — 2026-11-18

- Initial Rust integration for the maintained enzim WebKit engine.
- Toolkit-free sessions, profile isolation, navigation and input APIs.
- enzUI widget integration, GPU frame import and accessibility.
- Host-controlled permissions, credential protection and renderer sandbox checks.
- Clipboard, downloads, media, screen sharing and page export integration.
- Verified external native runtimes and shared Flatpak runtime support.
- enzUI Alpha 0.2 and matching public foundation dependencies.
